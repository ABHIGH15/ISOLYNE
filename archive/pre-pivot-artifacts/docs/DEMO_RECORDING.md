# Demo Recording Guide — Final Sprint

**Artifact priority:** This video is the product.  
**Pass 2:** [`PASS_2_SILENCE.md`](./PASS_2_SILENCE.md) — film direction, not UI.  
**Source of truth:** [`DEMO_SCRIPT.md`](./DEMO_SCRIPT.md)

## Before you press record

1. Cold start the app (kill Expo Go / simulator fully).  
2. Ensure Hack Pass is **cleared** (Profile → Clear Hack Pass if needed).  
3. Stay on **Radar**. Never open Profile during the take.  
4. Phone in portrait. Brightness high. Do Not Disturb on.  
5. Prefer a clean session with no debug banners.  
6. Mute narration — UI must carry the story.

## Exact take (≤90s)

| Sec | Action |
|---|---|
| 0:00–0:01 | Splash / brand |
| 0:01–0:08 | Hold Radar — question readable |
| 0:08–0:14 | Tap **Three Generals** only |
| 0:14–0:28 | **SILENCE.** Finger off glass. Read → breathe → still nothing |
| 0:28 | Tap **Why?** only after the breath |
| 0:29–0:36 | Evidence readable |
| 0:36 | Continue → Suggested Lock |
| 0:37–0:46 | Hold lock |
| 0:46 | Continue → Recommendation |
| 0:47–0:56 | Hold recommendation |
| 0:56–1:00 | Scroll to Hack Pass if needed |
| 1:00 | Tap **Unlock Hack Pass** |
| 1:04–1:12 | Outcome |
| 1:12 | Continue → First-Hour (Before code step 1) |
| 1:16–1:25 | Hold |
| 1:25–1:30 | Back to Radar **or** edited end card |

**If Why? is tapped before a full breath after reading → re-record.**  
**If the take feels “slow” instead of “intentional” → re-record with cleaner holds, not faster taps.**

## Pass 2 review (muted, frame by frame)

Ask only:

> Does the viewer get enough time to **feel** the sentence before they are asked to do anything?
