## Five tests (applied to every pattern)

| Test | Bar |
|---|---|
| Screenshot | Wrong / why / next step obvious without context |
| Nod | “Yep… I’ve seen that” — recognition over education |
| Action | Lock executable in ≤1 minute |
| Ownership | Named seat or “pick one person by name” — never “the team should…” |
| Memory | Quotable Biggest Risk line |

## Biggest Risk structure

Observation → Consequence live in **evidence + narrative**.  
**Biggest Risk** is the emotional-cost punchline (what people remember).

## Consistency rules applied

- One voice: direct, slightly dry, never HR
- Locks always create an owner in ≤1 minute
- Evidence always countable facts (`{count}` / open needs)
- Distinct punchlines — no shared metaphors across patterns
- Gold keepers preserved: demo-owner, architecture-spiral, ai-overstaffed

## Intentionally unchanged (coverage)

No personality, skill scoring, ML prediction, GitHub intel, or idea judging.
