# Demo Script — 90 seconds (muted-first)

**Goal:** A judge understands SquadRadar with audio off.  
**Hero screen:** Biggest Risk — the **sentence**, not the label.  
**Pass 2:** Silence is the craft — cinema, not UI. Protect the breath until curiosity overtakes reflection.  
Film direction: [`PASS_2_SILENCE.md`](./PASS_2_SILENCE.md)

---

## Beat sheet

| Time | Visual | Silent story |
|---|---|---|
| 0:00–0:08 | Radar: “Should I join this team?” | Brand + question |
| 0:08–0:14 | Tap **Three Generals** | Choice |
| 0:14–0:28 | **Biggest Risk** — blank → sentence → nothing → breathe | Tension. **Do not tap.** |
| 0:28–0:36 | Tap **Why?** → Evidence | Understanding |
| 0:36–0:48 | Continue → Suggested Lock | Relief (“fixable”) |
| 0:48–0:58 | Recommendation 🟡 Join if… | Decisive |
| 0:58–1:10 | Unlock **Hack Pass** | Prevention |
| 1:10–1:25 | Outcome + First-Hour Plan | Confidence |
| 1:25–1:30 | Back to Radar / end card | Memory |

**Hero hold:** ≥12–14s before Why?. Steal time from elsewhere if needed — never from silence.

## Narration (optional; UI must work without it)

> Hackathons fail when you join the wrong team.  
> SquadRadar shows the Biggest Risk before you commit.  
> Then it tells you how to lock roles — and, with Hack Pass, your first hour.  
> Don’t predict success. Expose failure modes.
