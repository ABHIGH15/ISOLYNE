# Collaboration Intelligence System Architecture v1.0
STATUS: FROZEN

## 1. Core Thesis

Temporary teams fail when perceived shared reality diverges from actual shared reality.

Collaboration Intelligence detects, repairs, and preserves shared reality. It prevents teams from resetting to zero.

## 3. Two Intelligence Layers

### Execution Intelligence
**Purpose:** Prevent reality decay while the team exists.

| Gap | Repair Protocol |
|-----|-----------------|
| Ownership | Assignment |
| Consensus | Alignment |
| Interpretation| Definition |
| Integration | Specification |
| Execution | Diagnosis |
| Pivot | Reframe |

### Learning Intelligence
**Purpose:** Preserve reality gained after the team changes.

| Gap | Repair Protocol |
|-----|-----------------|
| Meaning | Framing |
| Learning| Reflection |

## 4. Universal Gap Contract

Every future capability or evaluator must definitively answer:

1. **What reality is hidden?**
2. **Who has a different perception?**
3. **Why does the gap remain invisible?**
4. **What is the smallest action that restores shared reality?**

If a feature cannot answer these four questions, it is project management—not Collaboration Intelligence—and must not be built.
