# Awareness Engine v1.0
STATUS: FROZEN

The Awareness Engine is complete. Its purpose is to detect, explain, and repair shared reality gaps during temporary collaboration.

The product is not helping teams work faster. It is preventing temporary teams from losing shared reality.

---

## The Intelligence Split

The engine is now formally divided into two distinct systems:

```
             Collaboration Intelligence

              Awareness Engine
                    |
        ----------------------------
        |                          |
 Execution Intelligence       Learning Intelligence

 Detect reality gaps         Preserve reality gains
```

---

## Validated Execution Intelligence Gaps

The execution layer contains 6 validated primitives that prevent a team from failing during the work phase.

| Gap | Core failure |
|-----|--------------|
| **Ownership** | Missing authority |
| **Consensus** | Hidden disagreement |
| **Interpretation** | Different meanings |
| **Integration** | Different system assumptions |
| **Execution** | Unknown blocker |
| **Pivot** | Outdated shared reality |

These are the core execution primitives. They must not be modified while building the Learning Intelligence layer.
