# SquadRadar Current State

## Product Identity

SquadRadar is a Collaboration Intelligence Engine.

It does not:
- manage tasks
- rank people
- monitor productivity
- replace PMs

It detects when teams believe they share reality but actually don't.

---

# Core Principle

Actual Shared Reality != Perceived Shared Reality

# Validated Gap Types

1. Ownership Gap
Hidden reality:
Nobody owns final decisions.

Repair:
Assignment


2. Interpretation Gap
Hidden reality:
People mean different things.

Repair:
Definition


3. Integration Gap
Hidden reality:
Systems/components assumptions differ.

Repair:
Specification


4. Execution Gap
Hidden reality:
Progress assumptions differ.

Repair:
Blocker exposure


5. Pivot Gap
Hidden reality:
Timeline and ambition conflict.

Repair:
Reframe


6. Meaning Gap
Hidden reality:
Same artifact, different story.

Repair:
Shared framing


7. Learning Gap
Hidden reality:
Team knowledge disappears after event.

Repair:
Memory
