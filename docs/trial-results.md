# Trial Results — Formation Protocol v0.1

> **Scenario:** Leadership Gap (4-person team, 0 owners)
>
> **Researcher prompt:** "This is a tool for teams. Tell me what you think is happening."

---

## Classification Guide

### ✅ Success
User understands the problem and acts without help.

**Indicators:**
- Describes the problem in their own words
- Taps the button without asking what it does
- Accepts the resolved state naturally

### ⚠️ Partial
User understands but hesitates.

**Indicators:**
- Reads the screen carefully (>10s)
- Hovers over the button
- Says something like "So I should press this?"
- Understands after resolution but needed extra time

### ❌ Failure
User requires explanation.

**Indicators:**
- "What is this?"
- "Why should I do this?"
- "What happens if I press?"
- Looks at researcher for guidance
- Doesn't connect the action to the consequence

## Decision After 5 Trials

- [ ] **If ≥4 Success:** Proceed to Align layer (Agree/Challenge)
- [ ] **If 2–3 Success:** Fix wording, consequence framing, or action label. Re-test.
- [ ] **If ≤1 Success:** Fundamental protocol failure. Revisit the Reveal → Commit model.
