# Shared Reality Gap Taxonomy v1.0
STATUS: FROZEN

## Core Invariant

A collaboration failure occurs when:
**Actual Shared Reality ≠ Perceived Shared Reality**

Collaboration Intelligence detects and repairs this specific divergence. It is not a recommendation engine, and it is not a productivity tracker. It is an awareness engine.

---

## Universal Pipeline

Every gap flows through this exact operational pipeline:

```
Signal
  ↓
Awareness Snapshot
  ↓
Gap Detection (Evaluator)
  ↓
Gap Classification
  ↓
Proposal (Diagnosis)
  ↓
Alignment Protocol (Repair Protocol)
  ↓
Commitment
  ↓
Memory
```

---

## Validated Gap Classes

The complete set of fundamental collaboration failure modes:

| Gap Class | Missing Reality | Diagnosis (Hidden Reality) | Repair Protocol |
|-----------|-----------------|-----------------------------|-----------------|
| **1. Ownership Gap** | Decision authority | No decision owner exists. | Assignment |
| **2. Consensus Gap** | Agreement state | People silently disagree. | Alignment |
| **3. Interpretation Gap** | Meaning | People mean different things. | Definition |
| **4. Integration Gap** | Interface contract | Assumptions differ across boundaries. | Specification |
| **5. Execution Gap** | Momentum / State | Progress stopped and blocker is unknown. | Diagnosis |
| **6. Pivot Gap** | Trajectory viability | Current plan cannot mathematically finish. | Reframe |
| **7. Narrative Gap** | Story / 'Why' | Technical reality exists but shared meaning does not. | Narrative Alignment |
| **8. Learning Gap** | Extracted value | The team's human capital and lessons are unrecorded. | Reflection |

---

## Evaluator Test Criteria

Every `GapEvaluator` must prove it belongs in the engine by answering:
1. **What reality is hidden?**
2. **Who believes something different?**
3. **Why would the gap remain invisible?**
4. **What minimum action restores shared reality?**
